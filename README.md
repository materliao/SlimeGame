# Slime 冒險遊戲 (Slime Adventure)

此專案為使用 **Python** 與 **Pygame** 函式庫開發的橫向捲軸動作遊戲。玩家將扮演一隻紅色史萊姆，在三條道路上切換、移動並擊敗不斷襲來的史萊姆與巨龍。

本專案同時展現了物件導向程式設計 (OOP) 的應用、遊戲狀態機管理以及動態動畫處理技術。

## 🚀 專案背景
本遊戲由 **長億高中程式設計研究社 (CYPC)** 創辦人廖翊安開發。作為社團教學示範專案，它展示了如何整合硬體邏輯思維與軟體開發，並透過模組化設計（Setting, Sprite, Stage, Main）來建構一個可擴充的遊戲系統。

## 🛠 核心技術
* **語言**: Python 3.x
* **核心庫**: Pygame
* **架構**: 模組化開發 (Separation of Concerns)
    * `main.py`: 遊戲主迴圈與渲染中心。
    * `sprite.py`: 角色與敵人的類別定義 (OOP)。
    * `stage.py`: 關卡邏輯與生成演算法。
    * `setting.py`: 全域變數、路徑管理與資源載入。

## 🎮 遊戲玩法
### 控制方式
* **方向鍵上/下**: 在三條道路之間切換。
* **方向鍵左/右**: 左右移動角色（具有 0.2 秒操作間隔限制以確保手感）。
* **空白鍵**: 發動攻擊。

### 關卡系統
遊戲共有六個關卡，難度隨進度提升：
1.  **Stage 1**: 基礎練習，史萊姆不會攻擊，擊敗 5 隻即可過關。
2.  **Stage 2-3**: 史萊姆開始主動攻擊，數量逐漸增加。
3.  **Stage 4-5**: 巨龍 (Dragon) 出現，擁有遠程/範圍攻擊判定。
4.  **Stage 6**: 史萊姆與巨龍混合編隊，考驗玩家反應。

### 角色機制
* **生命值 (HP)**: 初始為 10 點。若低於 10 點，每 4 秒會自動回復 1 點。
* **經驗值 (EX)**: 擊敗敵方可獲得經驗值，並反應在 UI 的經驗條上。
* **死亡判定**: HP 歸零時顯示 "Game Over" 並結束遊戲。

## 🛠 安裝與運行
1.  確保已安裝 Python 3.x。
2.  安裝 Pygame 函式庫：
    ```bash
    pip install pygame
    ```
3.  將所有專案檔案與 `assets` 資料夾放在同一目錄下。
4.  運行遊戲：
    ```bash
    python main.py
    ```

## 💡 開發亮點
* **動態動畫系統**: 透過 `animation_speed` 與 `current_image` 索引，實作流暢的角色動作切換。
* **碰撞偵測**: 精確計算玩家與敵人（Slime/Dragon）在不同道路 (`road_y`) 上的相對位置與攻擊判定。
* **自動化路徑管理**: 使用 `os.path.abspath` 自動抓取路徑，確保程式在不同設備上都能正確讀取資源檔案。
